## 📌 Project Overview
This repository contains the complete design, engineering drawings, and manufacturing specifications for a custom sheet-metal electrical enclosure. Designed for flat-pattern manufacturing (laser cutting and press-brake bending), this enclosure provides a durable, well-ventilated, and accessible housing for custom PCBs, power supplies, and active cooling assemblies.

## 📊 Key Specifications
| Parameter | Specification |
| :--- | :--- |
| **Part Type** | Open-Top Sheet Metal Enclosure |
| **Material** | Sheet Metal (e.g., 1.5 mm Mild Steel) |
| **Overall Size** | Approx. 170 mm × 150 mm (Base Dimensions) |
| **Manufacturing Process** | Laser Cutting → CNC Punching → Bending → Finishing |
| **Hardware** | 3 × Fan Mounts, Staggered PCB Mount Grid (15mm pitch), Lid Fastener Holes |
| **Bends** | 8 × 90° Downward Bends (per bend table A–H), 3 mm Inner Radius |

## 🛠️ Features
*   **Thermal Management:** Opposing side walls feature louvered ventilation slots (4.00 mm width, 6.50 mm spacing) alongside dedicated circular cutouts for a triple-fan array. 
*   **Custom I/O Access:** A dedicated rectangular cutout and circular vent pattern (Detail B) on the front panel for routing cables and external connectors.
*   **PCB Mounting Grid:** A staggered array of pre-drilled holes in the base plate to accommodate various internal component standoffs and PCB sizes.
*   **Assembly & Alignment:** Chamfered top flanges with pre-drilled mounting holes for securing a top lid. Includes 1.00mm corner reliefs and interlocking tabs to maintain structural rigidity without welding.

## 📂 Repository Structure

## 🚀 Getting Started
1. Review the `drawings/flat_pattern.dxf` file for laser cutting and CNC punching profiles.
2. Refer to the `Electrical_Enclosure_Specification.pdf` for the formal bend table (Tags A-H), exact tolerancing, and hole arrays.
